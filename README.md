# 훈민정음 집현전 공방 (한글 창제 원리 모둠 대항전 & 교과 해설 게임)

조선 집현전 학사가 되어 세종대왕의 어명에 따라 훈민정음의 제자 원리(상형, 가획, 이체, 병서, 삼재, 초출, 재출, 합성)를 통해 한글 단어를 직접 빚어보고, **교실에서 학생들이 모둠별로 협동하여 경쟁하고 깊이 있게 해설을 들을 수 있는 웹 교육 게임**입니다.

---

## 🎮 실행 방법

### 방법 1: 즉시 실행 (단일 PC 또는 탭 여러 개 분할)
* [index.html](file:///C:/Users/user/Desktop/orca/index.html) 파일을 웹 브라우저(Chrome, Edge 등)에서 더블 클릭하여 바로 실행합니다.
* 브라우저 내장 `BroadcastChannel` 및 `localStorage` 동기화 기술이 적용되어 있어, 탭을 여러 개 띄우면(예: 1모둠 학생 1, 1모둠 학생 2, 2모둠 학생 1 등) **별도 서버 없이도 실시간으로 서로의 완료 현황과 순위가 즉각 연동**됩니다.

### 방법 2: 교실 Wi-Fi 다중 기기 모드 (스마트폰, 태블릿, 학생 노트북)
교사 PC의 터미널/PowerShell에서 아래 명령어를 실행하면, 같은 교실 Wi-Fi 망에 접속한 학생들이 스마트폰이나 태블릿으로 주소를 입력해 동시에 참여할 수 있습니다:
```bash
node server.js
```
* 교사 PC: `http://localhost:3000`
* 학생 스마트폰/태블릿: 터미널에 표시되는 IP 주소 (예: `http://192.168.0.x:3000`)

## 🏆 모둠 대항전 시스템

1. **학생 각자 풀이 & 모둠 협동 완주**:
   * 각 학생은 상단 바에서 **[내 모둠 (1~6모둠)]**과 **[학생 번호]**를 선택하고 문제를 풉니다.
   * 학생 개인이 글자를 완성하면 "나의 풀이 완료! 모둠원들을 기다리는 중..." 상태가 됩니다.
   * **모둠원 전원이 모두 완성을 마쳐야 최종 완주로 인정**됩니다.
2. **실시간 모둠 완주 순위 판정**:
   * 모둠원 전원이 문제를 다 푼 순서대로 **1등(🥇 금메달, 100점)**, **2등(🥈 은메달, 80점)**, **3등(🥉 동메달, 60점)** 등수가 실시간으로 확정됩니다.
   * 상단 **[🏆 모둠 전광판]** 버튼을 누르면 대형 TV나 프로젝터에 띄울 수 있는 모둠별 진척도와 모둠원 개별 완료 상태를 한눈에 볼 수 있습니다.
3. **환경 설정 (⚙️ 설정 버튼)**:
   * 학급 상황에 맞게 **모둠 수(2~6개)**와 **모둠당 인원 수(1~5명)**를 자유롭게 설정할 수 있으며, 변경 즉시 모든 연결 기기에 동기화됩니다.

## 📖 문제별 심층 해설 화면 (교과 수업용 슬라이드)

각 문제가 끝난 후(또는 상단 **[💡 문제 해설 보기]** 버튼 클릭 시), 교사와 학생들이 함께 보며 정리할 수 있는 교과 해설 화면이 제공됩니다:

1. **🏁 모둠별 완주 순위 발표**: 소요 시간과 획득 점수 발표
2. **🔍 음절별 제자 원리 완전 분석**:
   * **초성(첫소리)**: 발음기관 상형(치·설·순·아·후) ➔ 가획 ➔ 각자병서 계보도 및 해설
   * **중성(가운뎃소리)**: 삼재(천·지·인) ➔ 초출(음양) ➔ 재출 ➔ 합성 계보도 및 해설
   * **종성(받침)**: 종성부용초성(終聲復用初聲) 및 합용병서(겹받침) 해설
3. **🗣️ 국어 수업 탐구 & 토의 마당**: 교과서 연계 생각거리 질문 제공
4. **[다음 문제로 함께 진행 ➔]**: 교사가 버튼을 누르면 다음 단어로 넘어가 새로운 대결이 시작됩니다.

## 🌟 한글 창제 원리 조작 메커니즘

### 1. 자음 창제소 (초성·종성)
* **상형(象形) 기본자**: `ㄱ`(아음), `ㄴ`(설음), `ㅁ`(순음), `ㅅ`(치음), `ㅇ`(후음)
* **가획 (加劃)**: `ㄱ`➔`ㅋ`, `ㄴ`➔`ㄷ`➔`ㅌ`, `ㅁ`➔`ㅂ`➔`ㅍ`, `ㅅ`➔`ㅈ`➔`ㅊ`, `ㅇ`➔`ㅎ`
* **각자병서 (各自並書)**: 된소리 만들기 (`ㄱ`➔`ㄲ`, `ㄷ`➔`ㄸ`, `ㅂ`➔`ㅃ`, `ㅅ`➔`ㅆ`, `ㅈ`➔`ㅉ`)
* **이체 (異體)**: 모양을 달리한 글자 (`ㄴ`➔`ㄹ` 반설음)
* **합용병서 (合用並書)**: 서로 다른 두 자음을 결합하여 겹받침 생성 (`ㄹ`+`ㄱ`➔`ㄺ`, `ㄱ`+`ㅅ`➔`ㄳ`, `ㅂ`+`ㅅ`➔`ㅄ` 등)

### 2. 모음 창제소 (중성)
* **삼재(三才) 기본자**: `ㆍ`(하늘 천), `ㅡ`(땅 지), `ㅣ`(사람 인)
* **초출 합성 (初出)**: 하늘(ㆍ)의 위치에 따라 방향과 음양 선택
  * `ㆍ` + `ㅡ` ➔ `ㅗ`(하늘이 땅 위, 양) / `ㅜ`(하늘이 땅 아래, 음)
  * `ㆍ` + `ㅣ` ➔ `ㅏ`(하늘이 사람 밖, 양) / `ㅓ`(하늘이 사람 안, 음)
* **재출 합성 (再出)**: 초출자에 하늘(ㆍ)을 한 번 더 더해 소리가 거듭남 (`ㅛ`, `ㅠ`, `ㅑ`, `ㅕ`)
* **모음 합성 (합용)**: 완성된 모음끼리 결합하여 복합 모음 제작 (`ㅏ`+`ㅣ`➔`ㅐ`, `ㅗ`+`ㅏ`➔`ㅘ`, `ㅡ`+`ㅣ`➔`ㅢ` 등)
