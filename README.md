# 훈민정음 집현전 공방 (한글 창제 원리 모둠 대항전 & 교과 해설 게임)

조선 집현전 학사가 되어 세종대왕의 어명에 따라 훈민정음의 제자 원리(상형, 가획, 이체, 병서, 삼재, 초출, 재출, 합성)를 통해 한글 단어를 직접 빚어보고, **교실에서 학생들이 모둠별로 협동하여 경쟁하고 깊이 있게 해설을 들을 수 있는 웹 교육 게임**입니다.

---

## 🎮 실행 방법

인터넷과 Node.js가 필요합니다. 교사 컴퓨터에서 다음을 실행합니다.

```bash
node server.js
```

1. 교사 컴퓨터에서 `http://localhost:3000`을 열고 **선생님**을 선택합니다.
2. 교사 방은 자동으로 열립니다. 새 방의 기본 구성은 **6모둠, 모둠당 5명**입니다. 교사용 화면에 **Supabase 실시간 연결됨** 또는 **자동 동기화 중**이 표시되면 필요에 따라 모둠을 설정합니다.
3. 학생은 교사 화면의 QR을 스캔하거나 사이트의 **학생**을 선택한 뒤 교사가 보여 주는 방 코드를 입력합니다. QR에 교실 Wi-Fi 주소가 표시되는 경우 교사와 학생은 같은 네트워크에 있어야 합니다.
4. 학생마다 서로 다른 모둠과 학생 번호를 선택합니다. 새 방에서는 점수에 반영되지 않는 **연습 문제 ‘가방’**을 먼저 자유롭게 풀어 볼 수 있습니다. 교사가 **연습 게임 시작**을 누르면 3분이 시작되고 제출할 수 있습니다. 연습 후 1라운드를 선택하면 정규 대결이 시작됩니다.

교사 화면을 새로고침하면 같은 방의 모둠 구성과 문제, 점수를 복원합니다. 늦게 입장하거나 다시 연결한 학생도 현재 상태를 받습니다. 진행 중 모둠 구성이나 인원수를 바꾸면 현재 라운드의 제출과 점수가 초기화됩니다. 이전 방에서도 **연습 게임 시작**을 누르면 누적 점수를 보존하며 연습할 수 있습니다. 기존 연습 문제가 있으면 그 단어를 사용하고, 없으면 ‘가방’을 추가합니다. 현재 풀이 중인 내용은 초기화됩니다.

각 문제의 제한 시간은 3분입니다. 교사 화면에는 경과 시간이, 학생 화면에는 남은 시간이 표시됩니다. 3분이 지나면 제출이 마감되고 미완주 모둠은 0점입니다. 모두 완주하면 시계가 멈춥니다. 기존에 진행 중인 문제에는 영향을 주지 않으며, 다시 시작하거나 다음 문제를 선택하면 3분 제한이 적용됩니다.

학생에게 방을 찾을 수 없다고 표시되면 교사 화면의 연결 상태와 학생 화면의 방 코드가 같은지 확인하세요. 학교 네트워크에서 실시간 통신이 차단되면 자동으로 약 3초 간격으로 동기화합니다.

`localhost`에서 QR을 띄우면 로컬 서버가 가능한 교실 Wi-Fi 주소로 바꿉니다. 휴대전화에서 접속되지 않으면 터미널에 표시된 IP 주소, 같은 Wi-Fi 연결 및 교사 PC 방화벽의 3000번 포트를 확인하세요. `file://`로 파일을 직접 열면 휴대전화와 주소를 공유할 수 없습니다.

인터넷에 배포하려면 [배포 가이드](DEPLOY.md)를 참고하세요. 정적 사이트 배포 시에도 방 상태는 `cloud-sync.js`에 설정된 Supabase 프로젝트를 사용합니다.

### 보안 주의

현재 수업방은 로그인 없이 이용하며, 기존 `game_rooms`의 익명 접근 정책은 모든 방을 읽고 수정할 수 있습니다. 방 코드는 비밀번호가 아니며 교사·학생의 신원이나 제출 내용을 서버가 검증하지 않습니다. **학생 실명이나 개인정보를 입력하지 말고 평가용으로 사용하지 마세요.** 실제 운영에는 인증, 방별 접근 권한(RLS), 교사 권한 및 서버 측 제출 검증이 필요합니다.

### 테스트

```bash
node --test
```

## 🏆 모둠 대항전 시스템

1. **학생 각자 풀이 & 모둠 협동 완주**:
   * 각 학생은 상단 바에서 **[내 모둠]**과 **[학생 번호]**를 선택하고 문제를 풉니다.
   * 학생이 글자를 완성한 뒤 제출하면 다른 모둠원들의 제출을 기다립니다.
   * **모둠원 전원이 모두 완성을 마쳐야 최종 완주로 인정**됩니다.
2. **실시간 모둠 완주 순위 판정**:
   * 모둠원 전원이 완주한 순서에 따라 **1등 10점, 2~3등 5점, 4등 이하 2점**을 받습니다. 미완주 모둠은 0점이며 연습 문제는 점수에 반영되지 않습니다.
   * 교사 화면의 모둠 전광판에서 진척도와 모둠원별 제출 상태를 볼 수 있습니다.
   * 라운드 점수는 누적되며 **[🏆 누적·최종 점수]**에서 라운드별 점수와 전체 순위를 확인합니다. 마지막 라운드를 모든 모둠이 완주하면 최종 결과가 표시됩니다.
   * 이미 진행한 문제를 다시 시작하거나 단어를 수정하면 해당 라운드의 점수만 초기화됩니다.
3. **환경 설정 (⚙️ 설정 버튼)**:
    * 학급 상황에 맞게 **모둠 수(2~8개)**와 **모둠당 인원 수(1~8명)**를 설정할 수 있으며, 저장 후 연결된 학생에게 동기화됩니다.
4. **미션 단어 설정**:
    * 교사는 **[✏️ 미션 단어 설정]**에서 연습·정규 미션을 수정하거나 정규 미션을 추가할 수 있습니다. 한글 음절 1~10자로 입력하며 학생 화면에도 즉시 반영됩니다.

## 📖 문제별 심층 해설 화면 (교과 수업용 슬라이드)

각 문제가 끝난 후 교사 화면의 **[💡 문제 심층 해설 슬라이드 열기]** 버튼을 누르면 함께 보며 정리할 수 있는 교과 해설 화면이 제공됩니다:

1. **🏁 모둠별 완주 순위 발표**: 소요 시간과 획득 점수 발표
2. **🔍 음절별 제자 원리 완전 분석**:
   * **초성(첫소리)**: 발음기관 상형(치·설·순·아·후) ➔ 가획 ➔ 각자병서 계보도 및 해설
   * **중성(가운뎃소리)**: 삼재(천·지·인) ➔ 초출(음양) ➔ 재출 ➔ 합성 계보도 및 해설
   * **종성(받침)**: 종성부용초성(終聲復用初聲) 및 합용병서(겹받침) 해설
3. **🗣️ 국어 수업 탐구 & 토의 마당**: 교과서 연계 생각거리 질문 제공
4. **[다음 문제로 함께 진행 ➔]**: 교사가 버튼을 누르면 학생들도 다음 단어로 넘어가 새로운 대결이 시작됩니다.

## 🌟 한글 창제 원리 조작 메커니즘

### 1. 자음 창제소 (초성·종성)
* **상형(象形) 기본자**: `ㄱ`(아음), `ㄴ`(설음), `ㅁ`(순음), `ㅅ`(치음), `ㅇ`(후음)
* **가획 (加劃)**: `ㄱ`➔`ㅋ`, `ㄴ`➔`ㄷ`➔`ㅌ`, `ㅁ`➔`ㅂ`➔`ㅍ`, `ㅅ`➔`ㅈ`➔`ㅊ`, `ㅇ`➔`ㅎ`
* **각자병서 (各自並書)**: 된소리 만들기 (`ㄱ`➔`ㄲ`, `ㄷ`➔`ㄸ`, `ㅂ`➔`ㅃ`, `ㅅ`➔`ㅆ`, `ㅈ`➔`ㅉ`)
* **이체 (異體)**: 모양을 달리한 글자 (`ㄴ`➔`ㄹ`, `ㅇ`➔`ㆁ`). 현대 받침 `ㅇ`은 옛이응 `ㆁ`으로 만든 뒤 완성된 음절에서 `ㅇ`으로 표시합니다.
* **합용병서 (合用並書)**: 서로 다른 두 자음을 결합하여 겹받침 생성 (`ㄹ`+`ㄱ`➔`ㄺ`, `ㄱ`+`ㅅ`➔`ㄳ`, `ㅂ`+`ㅅ`➔`ㅄ` 등)

### 2. 모음 창제소 (중성)
* **삼재(三才) 기본자**: `ㆍ`(하늘 천), `ㅡ`(땅 지), `ㅣ`(사람 인)
* **초출 합성 (初出)**: 하늘(ㆍ)의 위치에 따라 방향과 음양 선택
  * `ㆍ` + `ㅡ` ➔ `ㅗ`(하늘이 땅 위, 양) / `ㅜ`(하늘이 땅 아래, 음)
  * `ㆍ` + `ㅣ` ➔ `ㅏ`(하늘이 사람 밖, 양) / `ㅓ`(하늘이 사람 안, 음)
* **재출 합성 (再出)**: 초출자에 하늘(ㆍ)을 한 번 더 더해 소리가 거듭남 (`ㅛ`, `ㅠ`, `ㅑ`, `ㅕ`)
* **모음 합성 (합용)**: 완성된 모음끼리 결합하여 복합 모음 제작 (`ㅏ`+`ㅣ`➔`ㅐ`, `ㅗ`+`ㅏ`➔`ㅘ`, `ㅡ`+`ㅣ`➔`ㅢ` 등)
* 복합 모음을 만들 때는 **모음 보관**으로 한 모음을 보관하고 다른 모음을 만든 뒤 꺼내 합성할 수 있습니다.
