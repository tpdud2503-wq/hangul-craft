📋 복습 기록을 구글 시트에 연결

한 번 설정해 QR을 저장하면 교사 화면을 켜지 않아도 학생이 복습할 수 있습니다.

시트에는 학번 5자리·완료 단어·완료 시각만 기록합니다. 학번도 개인정보이므로 시트 공유를 제한됨으로 두고 학교의 개인정보 처리 기준을 확인해 주세요. 학번만으로는 본인을 확인할 수 없어 허위·대리 제출이 가능하므로 평가용으로 사용하지 마세요.

← 자율 복습으로 돌아가기

1. 새 시트에 기록 수신기 만들기

  1. 새 구글 스프레드시트를 만들고 공유 설정을 제한됨으로 둡니다.
  2. 시트에서 확장 프로그램 → Apps Script를 엽니다. 새 스크립트의 내용을 지우고 아래 코드를 복사해 붙여 넣은 뒤 저장합니다.
  3. 함수 목록에서 initializeReviewSheet를 선택해 실행하고 필요한 권한을 승인합니다. 시트에 복습 기록 탭이 생깁니다.

이 코드는 구글 스프레드시트 읽기·쓰기 권한을 요청할 수 있습니다. 코드를 확인한 뒤 신뢰할 때만 승인하고, 필요하면 전용 계정을 사용하세요. 구글의 미검증 앱 경고나 학교 계정 정책으로 배포가 차단될 수 있습니다.

2. 웹 앱 배포 후 QR 만들기

  1. Apps Script 오른쪽 위 배포 → 새 배포 → 웹 앱을 선택합니다.
  2. 실행 사용자: 나, 액세스 권한: 모든 사용자로 배포합니다. 웹 앱은 기록만 받고 시트 내용을 보여 주지 않습니다. 시트 자체의 공유 설정은 계속 제한됨이어야 합니다.
  3. 직접 만든 웹 앱 URL(끝이 /exec)을 아래에 붙여 넣고 연동 QR을 만듭니다. 해당 웹 앱 소유자가 학번을 볼 수 있으므로 다른 사람의 URL을 사용하지 마세요. 구글 계정 비밀번호나 시트 주소는 입력하지 마세요.

학생 화면 열기

학생은 이 연동 QR로 접속해야 시트에 기록됩니다. 연결 후 실제 학생 학번 대신 가상의 5자리로 테스트하고 테스트 행을 직접 지워 주세요.
